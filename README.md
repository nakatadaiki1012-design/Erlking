# 魔王（シューベルト）鑑賞アプリ

中学1年生の鑑賞の授業で使うための Web アプリです。インストールは不要で、ブラウザで開くだけで使えます。

- **先生用**（`teacher.html`）：電子黒板やプロジェクターに大きく映して使う画面
- **生徒用**（`student.html`）：1人1台のタブレットで、自分で操作する画面
- 入口（`index.html`）から、どちらかを選べます

どの画面も、スクロールしなくても1画面に収まるように作っています。

## 4つのモード

| モード | 内容 |
|---|---|
| **ガイド** | 曲を豊かに聴くための「聴きどころ」11こを、順番にたどります。①はじめに（シューベルト・ゲーテ・リート） ②ピアノの前奏 ③声の歌い分け ④旋律の形 ⑤魔王のさそい ⑥子どもの叫び ⑦父と子 ⑧調の変化（長調・短調・転調） ⑨3回目の魔王 ⑩最後の場面 ⑪まとめ。それぞれ「聴く前に」の問い → 該当部分だけを聴く → 「わかったこと」で確かめる、の流れです。先生用は「わかったこと」を1つずつ見せられ、生徒用は気づいたことを書くメモ欄があります（タブレットに保存）。 |
| **ことばのヒント** | 「どんな音？（音のようす）」と「どう感じた？（感じたこと）」のことばの一覧。生徒用はことばを押すとメモに入ります。書き方の型「（音のようす）なので、（感じたこと）と感じた。」つき。 |
| **鑑賞シート**（生徒用） | 書いたメモを、聴きどころごとにまとめて表示。名前を入れて印刷できます。 |
| **聴く** | 曲に合わせて「今歌っている人物」と歌詞（日本語／ドイツ語）が切りかわり、その場面の聴きどころ（💡）も出ます。下の色の帯を押すと、その場面から再生できます。「名前をかくす」にすると、だれが歌っているかを考えながら聴けます。 |
| **くらべる** | 語り手・父・子ども・魔王・ピアノを、1つずつ聴きくらべます。子どもの叫び「お父さん！」の3回を、続けて聴くこともできます。生徒用では、声の感じを表すことばを選んでから「ポイント」を見ます。 |
| **クイズ** | 流れた部分を「だれが歌っているか」当てる10問のクイズです。先生用は「答えを見る」でみんなに答えを見せ、生徒用は自分で答えて点数が出ます。 |

## イラストとピアノの図

- 人物（語り手・父・子ども・魔王）のイラストが、「聴く」「くらべる」「ガイド」に出ます。3回目の魔王は、こわい顔に変わります。
- **ピアノの弾き方の図**：点が「音」で、上ほど高い音、右ほどあとの音です。右手の「タタタ タタタ」（三連符）、左手の「グワーッとかけ上がる」動き、魔王の部分の伴奏（はずむ形・ゆれる形）、最後にピアノが止まるところを図にしています。曲が流れている間は、点がリズムに合わせて光ります。
- ガイドでは、聴きどころごとに図が出ます（声の高さくらべ、だんだん高くなる叫び、父と子のやりとり、やさしい魔王→こわい魔王 など）。
- イラストはすべてこのアプリのために描いたもので、著作権の心配はありません。

## 鍵盤アニメーション

- 「聴く」モードの「鍵盤」ボタン、またはガイドの図の右上「図／鍵盤」で出せます。
- 曲に合わせて、ピアノの鍵盤が押し下げられて、もどります（押されている鍵盤はオレンジ）。同じ鍵盤の連打も、1回ずつ押して離すのが見えます。
- 「落ちてくる音も出す」にすると、上から音のバーが落ちてきて、鍵盤にとどいた時に押されます（リズムが見やすい）。「歌の音も出す」にすると、歌の音の高さもむらさきで出ます。
- 音のデータ（`js/notes.js`）は、入っている録音から自動で読み取ったものです。①録音を「歌」と「ピアノ」に分け（UVR の MDX-Net ボーカル分離モデル Kim_Vocal_2）、②ピアノは Basic Pitch（Spotify）、歌は pYIN で音の高さを読み取りました。自動なので、少しまちがいもあります。
- この録音は、教科書の楽譜と同じく低い声用に移調された「ヘ短調」で歌われています（もとの楽譜はト短調）。
- ほかの音源を読みこんだ時は、鍵盤アニメーションはこの録音のデータのままなので、合いません。

## 先生用のべんりな機能

- キーボード：スペース＝再生／停止、←→＝前／次の聴きどころ・場面、1〜4＝モードの切りかえ、Enter＝ガイドの「わかったこと」を1つ見る・クイズの答え→次へ、H＝名前をかくす、L＝歌詞の切りかえ、F＝全画面
- ⚙（設定）
  - **表示と音源**：名前・歌詞の出し方、ほかの音源（先生の CD から取りこんだファイルなど）の読みこみ。読みこんだファイルはそのパソコンの中だけで使い、インターネットには送りません。
  - **時間合わせ**：場面の区切りがずれている時に直せます。曲を流しながら、場面が変わるたびに「ここ！」を押すだけです。直した時間はそのパソコンに保存されます。

## 音源（著作権について）

- 曲（シューベルト）と詩（ゲーテ）は、著作権が切れています。
- 入っている録音は、Wikimedia Commons にある **CC BY 3.0** の録音です。
  - [Schubert's Erlkönig, D.328 - Michael Jackson.ogg](https://commons.wikimedia.org/wiki/File:Schubert%27s_Erlk%C3%B6nig,_D.328_-_Michael_Jackson.ogg)（演奏：Michael Jackson。IMSLP に投稿された演奏で、有名な歌手とは別の人です）
  - CC BY 3.0 は「演奏した人の名前とライセンスを書けば、自由に使ってよい」というライセンスです。アプリの中（先生用は⚙→キー操作・出典、生徒用は ⓘ）にも書いてあります。
  - ブラウザで再生できるように mp3 に変換しています。
- 日本語訳は、このアプリのために新しく書いたものです。
- 場面の区切りの時間は、この録音の音を調べて決めた **目安** です。少しずれている所があれば、先生用の「時間合わせ」で直してください。

## 参考にしたこと

授業の組み立て（セリフ当てクイズ、人物ごとの旋律のちがい、歌とピアノが半音でぶつかる響き、調の変化、音楽をあらわすことば、ワークシート）は、市販の授業教材の考え方を参考にしました。文章・図・イラストはすべてこのアプリのために新しく作ったもので、教材の内容は写していません。

## 公開のしかた（GitHub Pages）

1. GitHub のこのリポジトリで **Settings → Pages** を開く
2. 「Branch」を `main`、フォルダを `/ (root)` にして **Save**
3. 数分後に `https://nakatadaiki1012-design.github.io/Erlking/` で開けるようになります
   - 先生用：`…/Erlking/teacher.html`
   - 生徒用：`…/Erlking/student.html`
